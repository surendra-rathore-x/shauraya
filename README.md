# The Royal Rajput International School Website

## Files
- `index.html`: semantic page structure and content
- `styles.css`: responsive visual design, layout, and accessibility styles
- `script.js`: mobile navigation and demo enquiry form behavior
- `assets/`: extracted and deduplicated images from the original HTML

## Preview
Open `index.html` in a browser. Keep the `assets` folder next to it.

## Important
The enquiry form is a front-end demo only. It does not send or save enquiries.
Connect a backend or email service before using it for real admissions.
Contact details and school information are preserved from the supplied source and should be verified before publishing.
